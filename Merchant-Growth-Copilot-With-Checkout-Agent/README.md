## 💡 What is this?

**Merchant Growth Co-Pilot + Merchant Checkout Agent** combines two connected experiences:

### 📊 Merchant Growth Co-Pilot

An AI-powered merchant intelligence platform that helps merchants understand their business through:

- Dataset analysis
- Revenue diagnostics
- AI-generated insights
- Growth recommendations
- Simulations
- Actionable fixes
- Analysis history

### 🤖 Merchant Checkout Agent

A separate AI-commerce layer that allows an AI buyer to request a purchase from a merchant.

Instead of simply creating a traditional checkout page, the Checkout Agent evaluates the request against merchant-defined rules before any payment action takes place.

The agent checks:

- Product availability
- Stock
- Quantity limits
- Allowed categories
- Buyer budget
- AI spending cap
- Authorization
- Merchant approval requirements

Only when the request passes the required checks can a Razorpay Test Mode order be created.
